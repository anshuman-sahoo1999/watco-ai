System Mathematical & ML Model Core Documentation

This portal section details the time-series forecasting math, feature engineering formulas, and chemical/hydraulic calculations running on the SCADA backend.

1. Feature Ingestion & Lag Formulation

Water consumption is highly autocorrelated and follows strong daily patterns. The system engineers inputs dynamically from raw SCADA flow metrics:

  • Lags: Telemetry observations at past steps:
    $$\text{Lag}_k(t) = y(t - k)$$
    We use immediate lags (\(\text{Lag}_1\), \(\text{Lag}_2\)) to capture flow momentum, and a 24-hour seasonal lag (\(\text{Lag}_{24}\)) to capture yesterday's corresponding flow baseline.
  • Rolling Windows: Smoothed historical values computed on a shifted window to prevent data leakage:
    $$\text{Rolling Mean}_w(t) = \frac{1}{w} \sum_{i=1}^{w} y(t - i)$$
    $$\text{Rolling Std}_w(t) = \sqrt{\frac{1}{w-1} \sum_{i=1}^{w} (y(t - i) - \text{Rolling Mean}_w(t))^2}$$ We calculate a 3-hour window (\(w=3\)) to model flow baseline trends and short-term volatility.

2. Machine Learning Model: XGBoost Regressor

The system utilizes an Extreme Gradient Boosting (XGBoost) model consisting of regularized decision trees. At boosting step \(m\), a new decision tree \(f_m(x)\) is trained to minimize the objective function:

$$\mathcal{L}^{(m)} = \sum_{i=1}^{N} L(y_i, \hat{y}_i^{(m-1)} + f_m(x_i)) + \Omega(f_m)$$

Where \(\Omega(f_m)\) is the complexity regularization penalty:

$$\Omega(f) = \gamma T + \frac{1}{2} \lambda \sum_{j=1}^{T} w_j^2$$

Using a second-order Taylor expansion approximation for Mean Squared Error (MSE), leaf weights are optimized as:

$$w_j^* = -\frac{\sum_{i \in I_j} (\hat{y}_i^{(m-1)} - y_i)}{|I_j| + \lambda}$$

3. Sequential Autoregressive Multi-Step Forecasting

Predicting the future hours (e.g. 15:00 → 23:00) sequentially requires updating input lags autoregressively:

Recursive Loop Algorithm:
For each hour \(t\) from \(t_{\text{cutoff}} + 1\) to \(23\):
  1. Project future pressure \(P(t)\) and reservoir level \(L(t)\) from historical averages at hour \(t\).
  2. Assemble feature vector \(X(t) = [\text{hour}(t), \text{weekday}(t), \hat{y}(t-1), \hat{y}(t-2), y(t-24), \text{Rolling Mean}_3(t), P_{\text{proj}}(t), L_{\text{proj}}(t)]\).
  3. Predict \(\hat{y}(t) = \text{XGBoost}(X(t))\).
  4. Apply non-negative check: \(\hat{y}(t) = \max(0, \hat{y}(t))\) and write the value back into the timeline as an input for step \(t+1\).

4. Water Domain Physical Calculations

  • Volumetric Flow Accumulation: Approximated using a Riemann sum with hourly intervals (\(\Delta t = 1\) hr):
    $$V = \int_{t_0}^{t_1} Q(t) \, dt \approx \sum_{t=t_0}^{t_1} Q(t) \cdot \Delta t \quad [\text{m}^3]$$
  • Residual Chlorine Decay (First-Order Kinetics): Residual chemical disinfection drops in pipes due to bulk decay reaction kinetics:
    $$C(t) = C_0 \cdot e^{-k_b \cdot \Delta t} \quad [\text{ppm}]$$
    Disinfection warning alert checks are fired if levels exit the safe range (\(0.2 \text{ ppm} \le C(t) \le 2.0 \text{ ppm}\)).
  • Pipe Friction Head Loss (Hazen-Williams): Pressure drop in distribution lines is modeled by:
    $$h_f = 10.67 \cdot L \cdot Q^{1.852} \cdot C_H^{-1.852} \cdot D^{-4.87} \quad [\text{meters of head}]$$
